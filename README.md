# 카톡 카드 앱

카톡에 보낼 접속 링크 카드의 문구와 삽화를 미리 보고, 내 카톡 나와의 채팅방으로 전송하는 작은 앱입니다.

## 실행

```powershell
npm start
```

브라우저에서 `http://localhost:5188`로 접속합니다.

## 사용 방식

1. 삽화 링크, 화면 접속 링크, 인사말, 주제, 버튼 문구를 입력합니다.
2. 오른쪽 미리보기로 카드 모양을 확인합니다.
3. `내 카톡으로 전송`을 눌러 나와의 채팅방으로 보내거나, `카톡 공유하기`로 공유창을 엽니다.

카드의 버튼은 입력한 화면 접속 링크로 이동합니다.

카카오에서 버튼이 앱 주소로 열리면 `제품 링크 관리 > 웹 도메인`에 화면 접속 링크의 도메인을 추가해야 합니다. 예를 들어 버튼 링크가 `https://www.jw.org/ko/`라면 웹 도메인에 `https://www.jw.org`를 등록합니다. 앱 화면의 `화면 접속 링크` 아래에 등록해야 할 도메인이 표시됩니다.

## 삽화 기준

카카오 기본 피드 템플릿은 정사각형이 아닌 이미지를 가운데 기준으로 잘라 보여줄 수 있습니다. 가장 안정적인 삽화는 800x800 이상 정사각형 이미지입니다.

- `전체 보이기`: 흐릿한 확대 배경 위에 원본 그림을 중앙에 놓아, 그림은 안 잘리면서 빈 공간도 줄인 정사각형 이미지를 만들어 전송합니다.
- `가득 채우기`: 카드 영역을 꽉 채우지만 가장자리가 잘릴 수 있습니다.

외부 이미지가 브라우저 보안 정책(CORS) 때문에 변환되지 않으면 다른 이미지 링크를 사용해야 합니다.

## 카카오 설정

`내 카톡으로 전송`은 카카오 JavaScript SDK v1의 나에게 보내기 API를 사용합니다. 서버 없이 브라우저에서 바로 로그인 토큰을 받아 테스트하기 위해 v1 SDK를 씁니다.

- Kakao Developers에서 앱을 만들고 JavaScript 키를 발급합니다.
- 플랫폼의 Web 사이트 도메인에 실행 주소를 등록합니다. 배포 버전은 `https://cksomj.github.io`를 등록합니다.
- 카카오 로그인 활성화와 동의항목의 `talk_message` 권한을 설정합니다.
- 메시지의 버튼 링크로 쓰는 도메인은 카카오 앱 설정의 제품 링크/도메인 조건에 맞아야 합니다.

`내 카톡으로 전송`은 로그인 팝업이 필요합니다. 브라우저가 팝업을 막으면 외부 Chrome 또는 Edge에서 `http://localhost:5188`을 열어 테스트합니다.
